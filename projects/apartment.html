青年公寓服务系统

本科毕业设计（计算机科学与技术），前后端分离的完整全栈项目：Spring Boot + MyBatis-Plus + MySQL + Redis 后端，Vue3 + Element Plus + Vite 前端。覆盖用户管理、房源管理、在线预订、合同生成、缴费记录全业务链路。

Spring Boot Vue3 MyBatis-Plus MySQL + Redis JWT + RBAC

项目背景

城市化进程加快、青年群体流动性增强，青年公寓成为城市青年解决住房问题的重要选择。传统公寓管理依赖人工或通用系统，在房源信息管理、租客身份核验、在线预订缴费上效率低、信息不透明、体验差。本系统为中小型青年公寓的数字化转型提供完整方案。

项目亮点

不是"增删改查"级别：集成第三方实名认证实现年龄自动核验；用 Spring State Machine 管理房源生命周期；RBAC 三角色权限；敏感信息（密码、身份证号）加密存储；通过功能测试与性能测试。

architecture

系统架构

$ 前端 Vue3 + Element Plus + Vite
$ axios 请求 → JWT 鉴权
$ Spring Boot Controller / Service / Mapper
$ MyBatis-Plus 持久层 → MySQL 业务数据 + Redis 缓存
[+] 前后端分离部署, 角色: 管理员 / 管家 / 租客
modules

功能模块

用户管理

注册登录、实名认证、身份信息加密存储，年龄自动核验确保租客身份真实有效。

房源管理

房源信息的发布、编辑、上下架，生命周期状态机流转：待租 → 已租 → 退租，全程可追溯。

在线预订

租客在线预约看房、预订房源，订单状态与房源状态联动，避免重复预订。

合同生成

预订通过后自动生成合同，签约流程线上化，合同状态纳入状态机统一管理。

缴费记录

租金、水电等缴费记录线上化，账单明细可查，支持按租客与房源维度追溯。

权限控制

RBAC 权限模型：管理员、管家、租客三角色分级访问，接口层 JWT 鉴权拦截。

core design

核心设计

Spring State Machine 状态机

房源从"待租"到"已租"再到"退租"的完整生命周期由状态机驱动，非法流转被拦截，流转历史可追溯。

实名认证 + 年龄核验

集成第三方实名认证接口，自动校验租客年龄与身份真实性，从源头过滤违规入住。

数据安全

用户密码、身份证号等敏感信息加密存储，接口层 JWT 令牌鉴权，保障多端会话安全。

前后端分离

Vue3 + Element Plus 构建界面，Spring Boot 提供 RESTful API，Vite 工程化构建，独立部署。
