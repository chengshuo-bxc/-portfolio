企业公开舆情信息定向爬取

对标简历「企业公开舆情信息定向爬取 RPA 机器人」。本复现用新浪新闻搜索（免登录）定向采集指定企业舆情：标题指纹去重 → 词典情感标注 → HTML 看板推送。实测监控小米：15 条新闻，涨价类正确标负面。

多站点适配 标题指纹去重 词典情感标注 HTML 看板

项目背景

品牌/公关每天要盯自家企业、竞品在全网的新闻和舆论风向。舆情源从百度新闻、微博到垂直社区，且要自动去重、标情感、汇总成看板，替代人工每天手动搜。

核心难点

① 新闻源大多有反爬（百度有验证、微博要登录）；② 新浪新版搜索页的组合 CSS 选择器在 DrissionPage 里失效（.result-title a 取不到）；③ 情感标注要能识别行业语境（涨价对消费者是负面）。

sentiment

词典情感标注（零依赖）

情感标注第一版全"中性"——因为行业词没进词典。"涨价/调价/涨幅"在 51job 语境是中性词但对企业舆情是负面，扩充词典后实测纠正。[要点]

core/sentiment.py 
# 词典法: 统计正/负面词出现次数, 零第三方依赖, 可换 SnowNLP/大模型
POSITIVE_WORDS = {'利好','增长','突破','领先','获奖','签约','合作',
                  '降价','下调','回购','增持','中标','热销','销量新高'}
NEGATIVE_WORDS = {'投诉','亏损','下滑','违规','处罚','召回','裁员','诉讼',
                  '曝光','缺陷','事故','造假','质疑','暴跌',
                  '涨价','上调','涨幅','维权','赔偿','下架','故障','退货'}

def tag_sentiment(text: str) -> str:
    pos = sum(1 for w in POSITIVE_WORDS if w in text)
    neg = sum(1 for w in NEGATIVE_WORDS if w in text)
    return '正面' if pos > neg else ('负面' if neg > pos else '中性')

def title_fingerprint(title):
    norm = re.sub(r'[\s\W_]+', '', title.lower())
    return hashlib.md5(norm.encode()).hexdigest()
