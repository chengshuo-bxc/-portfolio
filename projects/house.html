全域房产智能监测

整合链家、贝壳、安居客等八大房产数据源，支撑区域定价参考、经纪人活跃度分析。链家/贝壳 SSR 低频直采，安居客 58 antibot 的 fzq cookie 纯 Python 生成，纯协议免浏览器，595 条入库。

595 条入库 fzq cookie 逆向 纯协议免浏览器 DrissionPage 兜底

项目背景

为房产经纪公司建全域房源数据库，多平台房源、经纪人、成交记录，跨平台关联构建房源档案，支撑区域定价与门店运营洞察。

核心难点

安居客被 58 antibot 风控拦截（翻页弹验证码）；链家/贝壳用 Scrapy 直连会被 TLS 指纹拦截，必须换方案。

reverse process

安居客 fzq 逆向过程

  • 侦察：链家/贝壳是 SSR（服务端渲染），低频 requests 直采稳定；但 Scrapy 的 TLS 指纹被拦，改用 requests
  • 安居客：被 58 antibot 拦，浏览器方案成本高、易弹极验滑块
  • 逆向 fzq_js cookie：定位 58 antibot 的生成逻辑，确认兜底分支算法
  • 算法还原：fzq = md5(时间戳 + namespace) + "_" + 时间戳 + "_0"，纯 Python 生成
  • 实测：首页 + 翻页全通过、无验证码，纯协议直采免浏览器免人工过码

# [逆向要点] 58 antibot 的 fzq_js cookie 生成算法(兜底分支, 实测通过)
# 签名 = MD5(时间戳 + namespace), 拼回 "_时间戳_版本"
def make_anjuke_fzq(ts=None, namespace="anjuke_ershoufang_pc",
                    version="0"):
    # version="0" 走兜底算法; 若服务端收紧校验, 再复现主分支(version=24)指纹
    ts = ts or str(int(_time.time() * 1000))
    if version == "0":
        sig = _hashlib.md5((ts + namespace).encode()).hexdigest()
    else:
        raise NotImplementedError("主分支(version=24)指纹拼接未复现")
    return f"{sig}_{ts}_{version}"


# 用法: requests 直连翻页, 带上生成的 cookie, 免浏览器免人工过码
def collect(city_url, pages):
    cookies = {"fzq_js_anjuke_ershoufang_pc": make_anjuke_fzq()}
    for p in range(1, pages + 1):
        url = LIST_TEMPLATE.format(page=p) if p > 1 else city_url
        status, body, final_url = retry.run(url=url, cookies=cookies, headers=headers)
        if status != 200 or any(m in final_url.lower() for m in VERIFY_MARKS):
            continue    # 被拦就跳过, 不硬闯
        rows = parse_anjuke(body, "anjuke", "shanghai")
        for r in rows:
            rec = clean_house_record(r)
