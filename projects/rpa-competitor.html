竞品官网动态内容自动化监控

对标简历「竞品官网动态内容自动化监控 RPA 机器人」。本复现用华为官网新闻中心（免登录）：定时采集板块内容，与历史快照差异比对，只检出新增 → 生成 Markdown 变化简报 → 邮件推送。首轮 12 条建基线，次轮 0 新增正确判重。

页面差异自动比对 增量内容定向爬取 简报生成 + 邮件推送 定时

项目背景

业务团队要第一时间知道竞品官网出了什么新东西（新闻、产品更新、招聘）。人工每天刷几个官网不现实——要自动盯、只报增量、还要汇总成简报推给团队。

核心难点

① 官网新闻是 JS 异步渲染，源码里抓不到；② "哪些是新增"要跟历史比，不能每次都全量报（会刷屏）；③ 差要比对要幂等——同一篇新闻重复抓不能产生脏数据。

diff

页面差异自动比对（增量检出）

快照表用 link UNIQUE 做唯一键：插入成功 = 历史里没有 = 新增；IntegrityError = 旧条目直接跳过。首次运行自动建立基线，之后只报增量。[要点]

core/diff.py 
def find_new(competitor, items):
    new_items = []
    for it in items:
        try:
            conn.execute(
                "INSERT INTO snapshot (competitor,section,title,link,first_seen)"
                " VALUES (?,?,?,?,?)",
                (competitor, it['section'], it['title'], it['link'], now))
            new_items.append(it)     # 插入成功 = 快照里没有 = 新增
        except sqlite3.IntegrityError:
            pass                     # link 已存在 = 旧条目, 跳过
    return new_items                 # 首次运行: 全部入库建基线, 无简报
$ 首次运行: [比对] 华为: 新增 12 / 12 → 生成简报(建基线)
$ 二次运行: [比对] 华为: 新增 0 / 12 → 无简报 [OK]
[+] 简报含标题/日期/链接, Markdown: output/变化简报_时间戳.md
