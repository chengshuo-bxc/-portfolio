招聘平台岗位信息自动化采集

对标简历「招聘平台岗位信息自动化采集 RPA 系统」（原为影刀 RPA）。本复现用 Python + DrissionPage 免登录采集 51job：监听岗位接口拿 JSON（绕开 sign 签名）、破解页面无限 debugger 反调试、按关键词抓取岗位入库导出 Excel。

接口监听采集 反 debugger 39 条真实岗位 Excel 导出

项目背景

HR / 运营要按关键词（爬虫工程师、Python 开发…）批量获取岗位的薪资、技能要求、公司信息，替代人工逐页复制。51job 是 Vue 单页应用，岗位由接口渲染，且搜索请求带 sign + decode__1048 加密参数。

核心难点

① 岗位列表是接口渲染，DOM 硬抓不靠谱；② 请求带签名不能直接 requests 打；③ 打开 F12 就触发无限 debugger 反调试（function anonymous{...debugger;...}），没法看 Network。

find api

用 F12 定位岗位接口（我自己上手）

  • 打开搜索页按 F12 → Network → 刷新 → 筛选 XHR → 看到 we.51job.com/api/job/search-pc
  • 接口带 sign（32 位 hex）+ decode__1048 加密参数 —— 直接 requests 会被拒
  • 响应是完整 JSON：jobName / provideSalaryString / jobSalaryMin / companyName / jobAreaString / workYearString / degreeString / jobTags / jobDescribe
  • 响应里有 totalCount（上海爬虫工程师共 679 个岗位），pageNum 翻页
anti debugger

破解无限 debugger（F12 一开就断）

页面埋了 debugger; 语句：只要开发者工具打开就不断暂停，无法看 Network。解法是页面加载前注入脚本，劫持 Function 构造器，把含 debugger 的代码直接过滤掉。[逆向要点]

core/api_client.py · ANTI_DEBUG 
# [逆向要点] debugger 常由 new Function 生成(function anonymous), 劫持构造器清洗
ANTI_DEBUG_SCRIPT = """
(() => {
  const clean = s => String(s).replace(/debugger\\s*;?/g, '');
  const OF = window.Function;
  const WF = function(...args) {
    if (args.length) args[args.length - 1] = clean(args[args.length - 1]);
    return OF(...args);
  };
  WF.prototype = OF.prototype;
  window.Function = WF;
  const OE = window.eval;
  window.eval = function(code) { return OE(clean(code)); };
})();
"""
# 用 CDP 在页面文档创建前注入, 之后 F12 随便开, 不再被断住
page.run_cdp('Page.addScriptToEvaluateOnNewDocument', source=ANTI_DEBUG_SCRIPT)
listen api

接口监听采集（绕开 sign 逆向）

不逆向签名——让页面自己请求接口（浏览器自带合法 sign），DrissionPage listen 监听响应直接拿 JSON。翻页点分页器，捕获新 pageNum 的响应。[要点]
