给服装企业做市场洞察，抓义乌购、苏宁、淘宝 3 大平台商品数据。淘宝 sign 算法逆向闭环 + DrissionPage 登录态复用，自建代理池，全链路跑通 3102 条真实商品入库。

3102 条真实入库 单 IP 1258 请求零封禁 sign md5 闭环验证 自建代理池

项目背景

电商 10 平台监测项目中的核心 3 平台（义乌购 / 苏宁易购 / 淘宝），采集商品信息、价格、规格、销量等关键数据，为服装企业提供市场洞察。

核心难点

淘宝 requests 直连直接被 FAIL_SYS_USER_VALIDATE 风控拦截（TLS 指纹），必须浏览器方案；三个平台反爬维度完全不同，需要三套方案。

reverse process

淘宝 sign 逆向过程

  • 抓包定位搜索接口：h5api.m.taobao.com/h5/mtop.taobao.wsearch.appsearch
  • 下断点找 sign 生成函数，确认输入：token + t + appKey + data
  • 还原算法：sign = md5(token & t & appKey & data字符串)，data 是紧凑 JSON（无空格、中文不转义）
  • Python 复刻后与浏览器请求的 sign 逐字对比，md5 一致才算闭环
  • token 来自登录态会话的 _m_h5_tk cookie，用 DrissionPage 登录一次，会话复用跳过反复验证码

# [逆向要点] 淘宝 mtop 接口签名:
# sign = md5( token & "&" & t & "&" & appKey & "&" & data字符串 )
# data 字符串为 JSON 序列化(无空格、中文不转义), 与前端行为一致
import hashlib, json, time

APP_KEY = "12574478"
H5API = "https://h5api.m.taobao.com/h5/{api}/{version}/"

def build_data_str(data):
    # 关键: separators 去掉空格, ensure_ascii=False 中文不转义
    # 序列化不一致会导致 sign 对不上, 这是最容易踩的坑
    return json.dumps(data, separators=(",", ":"), ensure_ascii=False)

def build_sign(token, t, data):
    # [逆向要点] token 来自登录态会话的 _m_h5_tk cookie
    # 拼接顺序不能变: token & t & appKey & data
    raw = f"{token}&{t}&{APP_KEY}&{build_data_str(data)}"
    return hashlib.md5(raw.encode()).hexdigest()

def build_params(api, version, token, data):
    # 组装完整 mtop 请求参数
    t = str(int(time.time() * 1000))          # 毫秒时间戳
    data_str = build_data_str(data)
    return {
        "jsv": "2.7.2",
        "appKey": APP_KEY,
        "t": t,
        "sign": build_sign(token, t, data),   # 关键签名
        "api": api,
        "v": version,
        "type": "jsonp",
        "data": data_str,
    }
