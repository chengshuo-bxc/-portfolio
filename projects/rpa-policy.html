行业政策文件定向采集与智能归档

对标简历「行业政策文件定向采集与智能归档 RPA 系统」。本复现用中国政府网最新政策（免登录）：政策列表 + 详情正文采集，按领域/发布部门自动分类归档，生成摘要索引。实测 20 条归档。

gov.cn 免登录 领域自动分类 增量更新 摘要索引

项目背景

政策法规每日更新，行业从业者要"发布后第一时间"拿到并按领域归档，替代人工每天逛官网检索下载。

核心难点

政府网站列表结构不规整；#list-1-ajax-id li 这种后代组合 CSS 选择器又失效（本项目第三次踩同一坑）；发布部门要从正文里识别，容易误抓（如"缴存比例由住房公积金管理委"）。

xpath

gov.cn 列表 + 详情正文

[逆向要点] DrissionPage 4.1 的后代组合 CSS（#list-1-ajax-id li）在多个站点都失效，但 xpath 稳定——这是本次复现踩出的一条通用规律。

config.SOURCES · 中国政府网最新政策 
SOURCES = [{
    "name": "中国政府网-最新政策",
    "url": "https://www.gov.cn/zhengce/zuixin/",
    # 组合 CSS '#list-1-ajax-id li' 失效 → xpath 直接抓政策链接最稳
    "list_sel": "xpath://a[contains(@href, 'zhengce')]",
    "title_sel": "",          # 空 = 用条目元素本身(即链接 a)
    "link_sel":  "",
    "date_sel":  "",
    "detail_sel": "#UCAP-CONTENT",   # 详情正文容器 (实测 3700+ 字全文)
}]
classify

领域 + 部门自动分类

core/classifier.py 
# 领域分类: 标题+正文命中关键词 → 归档到对应子目录
DOMAIN_RULES = {
    '数字经济': ['数字化','人工智能','数据要素','软件'],
    '能源环保': ['能源','电力','碳','环保','绿色'],
    '科技产业': ['科技','创新','产业','制造'],
    '民生医疗': ['医疗','教育','养老','住房'],
}
def classify_domain(title, text):
    for domain, kws in DOMAIN_RULES.items():
        if any(k in (title + text[:500]) for k in kws):
            return domain
    return '其他'

# 归档路径: archive/{领域}/{部门}/{标题}.md  (文件自动重命名与分类存储)
