题材库 · 题材掘金逆向

把题材小程序"大题材 → 小题材 → 股票"的整套接口逆向出来，用 Python 脚本直接拉数据，不依赖小程序。链路：微信加密包解包 → 静态分析定位接口 → mitmproxy 抓包 → WASM AES 响应解密。

735 个题材全量拉通 244 个源码文件 WASM 解密 发现 OSS 密钥泄露

项目背景

面试官给的题材小程序逆向任务。目标是"大题材 → 小题材 → 股票"递归数据全量拉通，产出不依赖小程序的独立脚本。

核心难点

响应是整体 AES 加密，密钥编译进包内的 WASM，JS 层完全不碰密钥；且有隐蔽环境校验（Referer + UA），token 对了也会 401。

reverse process

逆向过程（四步）

  • 挖包：从 PC 微信 4.x 缓存找到小程序 .wxapkg 加密包（appid: wx58eec6edd22c0ba2，靠 _pagesStock_ 分包名锁定）
  • 解包：V1MMWX 加密格式，用 AppID 做 PBKDF2 派生密钥 + AES-256 + XOR，解出 244 个源码文件
  • 找接口：静态分析定位域名 app.txcfgl.com/api，题材接口一套：/app/subject/list（735 个）、/app/subject/child-stock-tree/{id}（递归树）
  • 抓包解密：mitmproxy 抓真实 token 和调用链；响应 AES 加密，用 wasmtime 直接跑小程序自带的 aes_decryptor.wasm，链路全通
core code

核心代码（真实实现 + 注释）

逆向思路核心：不去逆密钥，直接复用目标自己的能力（跑它自己的 wasm），结果最一致也最稳。

wasm_decrypt.py 
# [逆向要点] 响应 AES 加密, 密钥编译在包里, JS 层不碰密钥
# 破法: 不去逆密钥, 直接用 wasmtime 跑小程序自带的 aes_decryptor.wasm
import wasmtime, os

def _get_module():
    # 从解包产物 raw/ 目录加载小程序自己的 wasm
    wasm = open(os.path.join(os.path.dirname(os.path.abspath(__file__)),
                             "raw", "aes_decryptor.wasm"), "rb").read()
    return wasmtime.Module(wasmtime.Engine(), wasm)

def decrypt_hex(hex_str):
    module = _get_module()
    store = wasmtime.Store(wasmtime.Engine())
    i32 = wasmtime.ValType.i32()
    # 注入两个空函数, 满足 wasm 导入(小程序内部实现, 不影响解密)
    a_a = wasmtime.Func(store, wasmtime.FuncType([i32, i32, i32], [i32]), lambda a, b, c: 0)
    a_b = wasmtime.Func(store, wasmtime.FuncType([i32], [i32]), lambda a: 0)
    inst = wasmtime.Instance(store, module, [a_a, a_b])
    exports = inst.exports(store)
    mem = exports["c"]; malloc = exports["f"]; free = exports["g"]
    decrypt = exports["e"]; free_memory = exports["i"]

    raw = hex_str.strip().strip('"').encode("ascii")
    ptr = malloc(store, len(raw) + 1)          # wasm 内存里分配密文空间
    mem.write(store, raw + b"\x00", ptr)       # 写入密文
    out_ptr = decrypt(store, ptr)              # 调用它自己的解密函数
    free(store, ptr)
    if out_ptr == 0:
        raise ValueError("解密失败")
    chunks = []; off = out_ptr
    while True:                                # 读明文直到 \x00
        b = mem.read(store, off, off + 1)
        if b == b"\x00": break
        chunks.append(b); off += 1
    free_memory(store, out_ptr)
    return b"".join(chunks).decode("utf-8")    # 明文 JSON
security finding

附加发现（安全审计）

硬编码阿里云 OSS 密钥

小程序配置里硬编码了 AccessKeyId / Secret，属于敏感信息泄露，攻击者可直接读写 OSS bucket。已标注风险并记录在复盘文档。

隐蔽环境校验

请求必须带 Referer: servicewechat.com/{appid} + MiniProgramEnv/Windows 的 UA，否则 token 对了也返回 401。
