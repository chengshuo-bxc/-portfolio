上市公司公告与研报自动聚合

对标简历「上市公司公告与研报自动聚合 RPA 爬虫系统」。本复现用东方财富公告接口免登录拉列表，PDF 自动下载（含 JS 挑战逆向破解），pypdf 解析正文，自动提取公告类型与金额，结构化入库。

JS 挑战逆向破解 PDF 自动下载解析 金额自动提取 增量入库

项目背景

投研团队要稳定拿到上市公司的公告和研报。公告列表有公开接口，但每份公告是 PDF，且 PDF 链接带 JS 挑战反爬——直接 requests 拿到的不是 PDF，而是一段混淆脚本。

核心难点

PDF 链接首次访问返回 988 字节混淆 JS（字符串数组 + 洗牌），挑战通过后写 cookie 再刷新才给真 PDF。需要理解并破解这段挑战，或让脚本自己算出 cookie。

js challenge

PDF 的 JS 挑战逆向（核心亮点）

requests 访问 PDF 链接返回混淆 JS。先是人工还原，再做通用解法。[逆向要点] 标实测结论。

挑战脚本结构（988 字节） 
// 字符串数组 + 洗牌 + 查表 = 字符串数组混淆(sojson 基础款, 不是真加密)
var _0x49a6 = ["wyeCN","4|2|0|3|1","wQzOV","split","iTyzs","pCQRM",
               "cookie","location...","WTKkN","bOYDu","dtzqS"];
(function(a,n){for(;--n;)a.push(a.shift())})(_0x49a6,0x147); // 洗牌 327 次
var _0x649a=function(a,n){a-=0;var e=_0x49a6[a];return e};    // 查表解密
// document.cookie = "__tst_status="+a(0)+"#;" → 拼常量出 cookie 后刷新

人工还原（验证理解）

洗牌 327 次 = 左移 327 mod 11 = 左移 8 位 → 查表解出常量顺序。手算：a(0)=943225403+963292024+1653318838=3559836265，a(1)="EO_Bot_Ssid=3495690240"。带这俩 cookie 重请求 → 拿到 119987 字节真 PDF（%PDF-1.7 验证）✅

通用解法（不怕换常量）

挑战脚本常量可能每次变。补个假 document 环境，让 Node 直接 eval 挑战脚本自己算 cookie，不依赖人工逆向。见下。

core/solve_challenge.js · Node 补环境通用解法 
const script = require('fs').readFileSync(0, 'utf-8'); // stdin 读挑战 JS
let cookies = [];
const document = {
    set cookie(v) { cookies.push(v); },   // 捕获脚本写的 cookie
    get cookie() { return cookies.join('; '); },
};
const location = { href: '', replace() {} };
eval(script);   // cookie 在同步阶段已写入
console.log(JSON.stringify(cookies));
// 输出: ["__tst_status=3559836265#;","EO_Bot_Ssid=3495690240;"]
