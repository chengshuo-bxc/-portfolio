本地生活平台商家信息批量采集

对标简历「本地生活平台商家信息批量爬取 RPA 工具」（单小时采集超 2000 条线索）。本复现走高德开放平台 Web 服务 API（纯 requests 免登录）：按区域/品类筛选商家，自动校验有效性导出标准化表格。实测 2.6 万条/小时。

官方 API 免登录 176 条有效线索 2.6 万条/小时 电话有效性校验

项目背景

本地服务业务拓展要批量拿商家线索（名称/地址/电话/评分）。原方案爬地图网页版，但本地生活平台反爬普遍严。

为什么放弃爬页面

实测三家全被挡：高德网页版弹 x5sec 滑块验证 iframe；百度地图只加载地图 UI、结果列表不渲染；58同城列表页要登录。→ 转 高德开放平台官方 API（个人免费 key，纯 requests，天然免反爬）。

api

高德 POI 搜索 API（纯 requests）

core/collector.py · AmapCollector 
# 高德 place/text: keywords=品类, city=城市码(310000 上海), offset=25/page 翻页
while True:
    data = requests.get(AMAP_API, params={
        'key': AMAP_KEY, 'keywords': category,
        'city': CITY_CODE, 'citylimit': 'true',
        'offset': '25', 'page': str(page_no),
        'extensions': 'all',          # all 才带扩展字段
    }, timeout=15).json()
    pois = data.get('pois', [])
    if not pois or len(pois) < 25:    # 不足一页 = 到末页
        break
    for p in pois:
        merchants.append({
            'name': p.get('name'), 'address': p.get('address'),
            'phone': (p.get('tel') or '').replace(';', ' '),  # 多电话分号分隔
            'score': p.get('rating', ''),
        })
    page_no += 1
validate

数据有效性校验（无效自动过滤）

core/validator.py 
PHONE_PATTERN = r'(1[3-9]\d{9})|(0\d{2,3}-?\d{7,8})'  # 手机 或 座机

def is_valid(m):
    for f in ['name', 'address']:      # 必填字段缺一即无效
        if not m.get(f): return False
    phone = m.get('phone', '')
    if phone and not re.search(PHONE_PATTERN, phone): return False  # 有电话但格式错
    return True

如实记录
